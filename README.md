# Portfólio — Júlio César

Portfólio acadêmico desenvolvido como trabalho da disciplina de Interface Homem-Máquina, no curso de Análise e Desenvolvimento de Sistemas do IF Baiano.

## Tecnologias
- HTML5
- CSS3

## Estrutura
- `index.html`: conteúdo e estrutura das seções.
- `css/style.css`: cores, organização visual, responsividade e efeitos.
- `imagens/`: espaço para adicionar a foto de perfil e as imagens dos projetos.
